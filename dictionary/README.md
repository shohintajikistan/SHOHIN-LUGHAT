# Dictionary dataset

The dictionary is maintained as sequential, frozen JSON groups under `dictionary/groups/`.

- `group_01.json`: entries 1–2,000; complete and frozen. Do not edit this file.
- `group_02.json` through `group_10.json`: future groups, each containing up to 2,000 entries.
- `additions.json`: supplemental entries not yet assigned to a frozen group; these are appended after all group files during the build.
- `words.json`: legacy source path retained for migration compatibility; it is currently empty.

Each record must contain:
- `number`: unique sequential position in the complete dictionary
- `en`: English headword or expression
- `tg`: Tajik translation in Cyrillic

Optional fields are `partOfSpeech`, `example`, and `source`. Categories are not used. The number is global across the complete assembled dictionary and must remain consecutive.

Run `python tools/prepare_dictionary.py` to assemble the group files and supplemental entries into the Android asset. Then run `python tools/validate_dictionary.py app/src/main/assets/dictionary/words.json`.

Never edit a completed group when adding later words. Add new records only to the next group file, preserving all existing entries. Remove exact duplicate English headwords, review conflicting translations, and keep source attribution. Do not use machine-generated placeholder translations to inflate the count. The release target is 20,000 unique entries.

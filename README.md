# SHOHIN LUGHAT

**English ↔ Тоҷикӣ** — an offline bilingual dictionary for Android.

## Project goals
- 5,000 English–Tajik dictionary entries
- 12 thematic categories
- English → Tajik and Tajik → English
- Offline search with no API, server, or remote database
- Favorites and recent search history
- Premium Emerald, Gold, Ivory, and Midnight visual identity

## Build
Every push to `main` starts the GitHub Actions workflow. The debug APK is uploaded as an Actions artifact.

## Current development stage
The initial native Android app foundation and interface are in place. The current bundled word list is a small starter dataset; the full reviewed 5,000-entry dictionary is a separate content milestone and is not yet complete.
